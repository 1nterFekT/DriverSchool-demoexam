# Как запустить

1. Нужно развернуть файл `demoexam.backup` у себя, чтобы база данных существовала
2. Затем нужно в файле `.env` поменять значения переменных на актуальные (чтобы подключиться к БД)
3. После чего необходимо в консоли прописать `npm i` для установки нужных пакетов
4. На последок нужно прописать `npm run dev` для запуска
